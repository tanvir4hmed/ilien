# ILIEN

Evidence-backed communication and coordination for people and AI-enabled applications.

ILIEN is being built to receive a request, contact authorized participants, collect information and decisions across channels, manage dependent replies and return a traceable result. The initial demonstration domain is textile and apparel manufacturing.

**Status:** initial integration contracts and documentation. Application runtime and deployment are not yet available. Capability descriptions are product intent, not a claim of a running service.

The demonstration will use synthetic manufacturing events and simulated operational actions, with real AWS communication services. Source applications retain responsibility for business analysis and operational changes.
