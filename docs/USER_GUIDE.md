# Workspace guide

ILIEN is designed to coordinate the communication; the workspace shows what has happened and provides configuration and recovery controls. It is not where staff need to carry out every normal conversation.

## Start and inspect a case

Use **Cases → Start case** to submit a supported synthetic source request, then open its map. Existing work appears in **Case list**. A case with missing workflow information shows **Needs routing review** instead of inventing a route.

The case view contains:

- **Flow** — current source, requirements, dependencies, departments, people, and source outcome;
- **Messages** — actual prepared/sent messages, provider events, replies, and channel state;
- **Outcome** — the communication result and source publication/acknowledgement state;
- **History** — evidence, case actions, and earlier result revisions.

Selecting a node or message opens its recorded details. The map is derived from the current case; it is not a preset diagram. A blocked node remains visible with the reason.

## Configure people and channels

In **Settings → People & channels**, add an approved person to the appropriate responsibility group, record the consent reference, and enable one or more channel bindings. The coordinator can use those bindings only when that person’s group is relevant to an active requirement. Adding a department or person does not make them automatically responsible for every issue; routing and responsibility are governed by the active workflow and published configuration.

## Understand status

| Status | Meaning |
| --- | --- |
| Waiting | Information or a prerequisite is still required. |
| Answered / Accepted | A participant response was recorded; acceptance depends on the configured rule. |
| Verified | An independent configured check accepted the current evidence. |
| Blocked / uncertain | A dependency, consent, provider path, or safe interpretation prevents progress. |
| Completed | Communication requirements are satisfied; it does not mean factory execution occurred. |
| Paused | New work in the selected stage is intentionally held. |

## When intervention is needed

Normal replies arrive through email or WhatsApp. Use the workspace only to configure people/channels, investigate a blocked or uncertain delivery, pause/resume a stage, or run an auditable recovery action. Do not mark a case complete because a message was sent or because an answer is implied.
